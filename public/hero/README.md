# Foto de fondo del Hero

La foto de fondo de la primera sección (justo debajo del header) es
`team.jpg`, y la usa `src/components/Hero.tsx` con un velo blanco
semitransparente encima para que el texto se siga leyendo bien.

Para cambiarla, sube la foto nueva a esta carpeta con el nombre
`team.jpg`. Conviene que sea JPEG o WebP y que no pese más de unos
300 KB: el PNG original pesaba 2 MB y en el teléfono tardaba en cargar.
Si usas otro nombre o formato, cambia el `import` en `Hero.tsx`.
